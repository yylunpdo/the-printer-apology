One-line apology from an office printer, written for the
[make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153)
bounty "The Printer Apology" (2 USDC, winner takes all).

## The line

> Sorry I jammed on page 47. You fed me paper thinner than your promises, then blamed the machine for choking on it.

114 characters — inside the 120-character gate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library and writes the line
deterministically to `/output/entry.txt`.
